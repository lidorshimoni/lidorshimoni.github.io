// ENGINEERING_NOTES & IMPLEMENTATION
A fire and smoke image classifier built in Keras: a frozen ImageNet-pretrained VGG16 base with a dense head, trained on a fire/smoke dataset in three classes (fire, neutral, smoke) at 150x150 input with data augmentation, early stopping and checkpointing. The repo includes training, continued-training, augmentation and test scripts.
// KEY_INNOVATIONS & BENCHMARKS
  • ›Transfer learning on VGG16.
