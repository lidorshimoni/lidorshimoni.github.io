// ENGINEERING_NOTES & IMPLEMENTATION
Engineered an autonomous real-time visual safety monitoring system (`Real-Time-Fire-Detection-CNN`) in Python with TensorFlow, Keras, and OpenCV. Curated and pre-processed a comprehensive image dataset containing diverse indoor and outdoor fire, smoke, and non-fire industrial scenes. Fine-tuned deep convolutional networks (including VGG16 backbones and lightweight CNNs) with spatial dropout and data augmentation. Implemented a real-time OpenCV video stream inference pipeline with dynamic bounding-box localization, confidence thresholding, and false-positive suppression against incandescent bulbs and sunsets for surveillance cameras and drone inspection.
