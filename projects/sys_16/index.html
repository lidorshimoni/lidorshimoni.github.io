// ENGINEERING_NOTES & IMPLEMENTATION
Developed an end-to-end computer vision generative system in Python using Keras and TensorFlow (`Face-DCGAN---Keras`). Built a deep convolutional generative adversarial network (DCGAN) with transposed convolutions, LeakyReLU activations, and batch normalization in the generator, pitted against a discriminator network with strided convolutions. Integrated OpenCV Haar Cascade classifiers to automatically detect, align, and crop facial datasets to uniform dimensions. Implemented latent space vector arithmetic, enabling smooth interpolation between synthetic identities and vector addition/subtraction to morph attributes (e.g. smiling, sunglasses, age).
// KEY_INNOVATIONS & BENCHMARKS
  • ›Engineered stable DCGAN training loop preventing mode collapse without gradient penalties.
  • ›Automated facial extraction pipeline using OpenCV Haar Cascades.
  • ›Demonstrated latent vector math: smiling vector + neutral face = synthesized smiling face.
  • ›Published complete open-source codebase on GitHub.
