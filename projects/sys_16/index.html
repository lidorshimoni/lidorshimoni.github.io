Deep learning generative modeling system using a conditional deep convolutional GAN to synthesize and edit faces by attributes (gender, hair, hat, eyeglasses, smiling), with a small desktop app.

// HARDWARE & ARCHITECTURE SPECIFICATIONS
FrameworkTensorFlow
ArchitectureConditional DCGAN (BatchNorm + LeakyReLU)
ConditioningAttribute Vectors (Bald, Blond, Eyeglasses, Hat, Smiling, ...)
PreprocessingOpenCV Haar-Cascade Face Detection & Alignment
Latent Dimension100
AppKivy Desktop UI
// ENGINEERING_NOTES & IMPLEMENTATION
A conditional deep convolutional GAN implemented in TensorFlow: a generator and discriminator trained with attribute condition vectors, with OpenCV Haar-cascade face detection and alignment in the data pipeline and latent-space interpolation between generated identities. A Kivy desktop app provides random-face, sketch and face-manipulation screens. Repo examples: 128x128 faces at 150 epochs (female, male, hat, bald, eyeglasses, blond, anime).
// KEY_INNOVATIONS & BENCHMARKS
  • ›Attribute-conditioned face generation and morphing.
  • ›Haar-cascade face alignment pipeline.
  • ›Latent-space interpolation between identities.
