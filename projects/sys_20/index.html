// ENGINEERING_NOTES & IMPLEMENTATION
Constructed and deployed a dedicated Pwnagotchi wireless security appliance. Built on a Raspberry Pi Zero W paired with a Waveshare 2.13-inch tri-color E-Paper display and a PiSugar LiPo battery management unit. Operates Bettercap in monitor mode while running an Advantage Actor-Critic (A2C) neural network algorithm that explores Wi-Fi channels, learns environmental channel occupancy, and selectively injects deauthentication association frames. Captures full WPA/WPA2 4-way handshakes and client-less PMKID frames into PCAP logs for offline Hashcat dictionary audits, while rendering emotive facial expressions based on internal neural reward states.
