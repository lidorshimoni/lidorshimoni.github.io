// ENGINEERING_NOTES & IMPLEMENTATION
Configured a HackRF One transceiver for RF security research and satellite communications. Built a dedicated Quadrifilar Helix (QFH) antenna using copper tubing, tuned to 137.5MHz to capture right-hand circular polarized (RHCP) signals from NOAA polar-orbiting satellites during overhead passes. Decoded raw Automatic Picture Transmission (APT) audio using SDR# and WXtoImg to extract live high-resolution cloud cover and sea temperature imagery. On the security front, used Universal Radio Hacker (URH) to capture, inspect, and analyze fixed and rolling code transmissions from sub-GHz ISM band keyfobs (315MHz/433MHz), documenting replay and rolljam vulnerabilities.
