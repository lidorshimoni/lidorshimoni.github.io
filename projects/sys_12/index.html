// ENGINEERING_NOTES & IMPLEMENTATION
Designed an open-source flight control system (`RCPlaneESP23`) for lightweight RC aircraft, eliminating traditional radio transmitters in favor of direct high-speed Wi-Fi telemetry. The ESP32 acts as an autonomous Access Point running an asynchronous HTTP/WebSocket server that serves an interactive dual-axis virtual joystick web interface. Streams live 6-axis IMU attitude telemetry (MPU6050 accelerometer and gyroscope) displaying a real-time artificial horizon, Wi-Fi RSSI signal strength, and battery voltage. Computes differential thrust mixer algorithms to drive dual brushless ESCs and servo control surfaces with sub-20ms latency.
// KEY_INNOVATIONS & BENCHMARKS
  • ›Zero transmitter required: fly aircraft directly from any smartphone or tablet browser.
  • ›Real-time sensor telemetry streaming (pitch, roll, yaw, battery voltage, RSSI).
  • ›Differential motor thrust mixer for high-agility rudder-less steering.
  • ›Fail-safe auto-throttle cut upon packet timeout or Wi-Fi disconnection.
