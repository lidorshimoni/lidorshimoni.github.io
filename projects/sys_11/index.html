// ENGINEERING_NOTES & IMPLEMENTATION
Transformed an entry-level 3018 CNC router into a precision laser engraver and plotting machine. Replaced flexible plastic structural joints with CNC-milled aluminum plates and added brass anti-backlash spring nuts on all leadscrews to eliminate backlash. Installed a 5.5W 450nm compressed-spot diode laser module with dynamic PWM laser power modulation in GRBL. Furthermore, patched and customized the GRBL 1.1f firmware on GitHub to support 28BYJ-48 unipolar stepper motors on secondary plotting axes, allowing 3-axis continuous pen plotting and vector engraving.
