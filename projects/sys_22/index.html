// ENGINEERING_NOTES & IMPLEMENTATION
Architected a local-first, zero-cloud home automation and environmental telemetry infrastructure running Home Assistant OS on a dedicated Raspberry Pi 4. Integrated an external Texas Instruments CC2652P Zigbee 3.0 USB coordinator with high-gain dipole antenna, running Zigbee2MQTT to orchestrate over 40 wireless sensors (temperature, humidity, millimeter-wave human presence, door contacts, and power meters). Deployed custom ESP32/ESP8266 microcontrollers running ESPHome over an isolated IoT VLAN communicating via an encrypted local MQTT broker, logging all environmental telemetry into InfluxDB and Grafana with zero external cloud dependencies.

  • ›100% offline functionality: all lights, climate control, and security run locally.

  • ›Real-time power monitoring across appliances with automated peak-tariff shifting.
  • ›Long-term telemetry logging with InfluxDB and custom Grafana dashboards.
